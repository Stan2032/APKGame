# ARCHITECTURE.md — code map + data flow (dense, agent-oriented)

## Supporting trees (not code)
`tools/` — `gen_sfx.py` (synthesized SFX), `store_assets.py` (icon + feature graphic), `verify_release_apk.py` (CI: permission allowlist, R8 keep-rule survival, size budget). `store/` — generated listing graphics. `feedback/` — player-report inbox/archive + triage protocol.

## Module rule
`:core` = every rule, deterministic, JVM-only, unit-tested. `:app` = presentation/IO only. If a change involves "who wins / what's earned / where things move" it belongs in :core.

## :core file map (io.github.stan2032.gravitygambit.core)
- `Rng.kt` — SplitMix64 + static `mix(a,b)` seed derivation. FROZEN constants (D-5).
- `Model.kt` — Vec2, GameMode, Body(+BodyKind STAR/PLANET/REPULSOR/COMET/PULSAR; motion and pulsar mass are pure functions of the integer tick, never mutable state), Station, `Gate`, SystemSpec (+`objectiveId`/`markedBody`/`gates`/`gambitMasks`), TurnInput (quantized: angleDeci 0..3599, power 0..1000, brakeTick), ProjectileType enum (damage/radius/maxPowerFrac/splits/canBrake), `Tuning` (ALL physics+scoring constants; see TUNING.md).
- `Gambit.kt` — the declarable constraints, each with a `satisfiedBy(ShotResult)` decided purely from measurements the simulation took. Rules only; no state.
- `Simulation.kt` — `LiveShot`: tick-stepped shot sim (semi-implicit Euler, dt=1/60, softened gravity, splits, brake, collisions, bounds, style detection, FNV-1a hash folding every 8 ticks + events). `ShotResult`. `Preview.trajectories()` (aim preview = same sim, capped ticks). `ProjView` for rendering.
- `MatchEngine.kt` — turn order, HP, damage, daily scoring+target relocation (`DailyLogic`, seeded by hit count), stars, over/winner logic, combined match hash. `MatchReplayer.rebuild()` = verification path (same engine ⇒ can't diverge).
- `Generator.kt` — `SystemGenerator.generate(seed,difficulty,mode)`: candidate layout (rejection placement) → solver (180 angles × 5 powers, STANDARD, 600 ticks) → accept iff hitRate ∈ band; duel = both-sides + ratio ≤4 fairness; 24 attempts → nearest-miss fallback → hardcoded fallback. `NameGen`, `Seeds` (campaign/daily/duel seed derivation, difficulty curve, LEVELS_PER_SECTOR=12, LAUNCH_EPOCH_DAY=20666).
- `Replay.kt` — `MatchRecord`, `ShareCodec` ("GG1."+base64url: magic/ver/mode/diff/seed/turns[8B each]/hash/crc32; tolerant substring decode; range-validated). `decodeAndVerify()` = decode → regenerate → resim → hash compare → `VerifiedMatch`|null.
- `Economy.kt` — `Profile` (full save state, kotlinx-serialization JSON, ignoreUnknownKeys⇒forward-compatible), `Economy` (trails, projectile unlocks star+dust gates, preview tiers 90/180/270 ticks, rewards, SECTOR_UNLOCK_STARS=20), `AdRewards` (watch ✦40 ×5/day; pass ×2 + ✦50/day), `Iap` (4 INAPP incl. `season_pass` + 2 SUBS ids).
- `Expedition.kt` — the run mode (Stage D): `Run` state (seed/depth/fuel/score/wrecks) with pure transitions `afterClear`/`afterWreck`, `routesFor` offering one SAFE/RICH/UNKNOWN `Leg` per junction (deterministic in seed+depth, so a junction cannot be rerolled), `Mutator` run-rules, and the fuel economy. **A leg is an ordinary CAMPAIGN match** — this file never touches MatchEngine, ShareCodec or the hash (D-34). `travelCost` rises without bound against a derived `MAX_REFUND`, which is what makes runs provably finite.
- `Ambience.kt` — the generated pad: `voicesFor(SystemSpec)` derives one partial per body (pitch from mass, phase from position, harmony set from the objective) and `render()` mixes them to a seamless 7s 16-bit mono loop. Periodicity is stored as *integer cycles per loop*, never hertz, which is what makes the seam exact; roots are multiples of 80 so every just-intonation ratio lands whole. A pulsar's tremolo runs at its real gravity period (`AmbienceWav` writes samples to .wav for listening). Never hashed, never on the wire — see AUDIO.md.

- `ui/screens/SeasonScreen.kt` — the season track: tier + XP bar + days left, a lazy 50-tier horizontal ladder showing both lanes (auto-scrolled to the player's tier), claim-all, and the pass offer (hidden unless billing can serve it). Rules live in `:core` `Season.kt`; this is presentation only.
- `ui/screens/` — Common (ScreenFrame/SectionCard/typography), Home, Campaign (sector cards, ★-gated levels), Duel (hot-seat / create-code / paste+validate / resume-last), Shop (unlocks, preview tiers, trails, free-stardust [ad], Ad Pass subs, IAP — every section self-hides when unavailable), Settings (haptics, privacy blurb, reset w/ confirm), Help.
- `ui/game/MatchController.kt` — presentation FSM around MatchEngine: `Phase` AIMING→FLYING→RESOLVING→(HANDOFF|AIMING|OVER); aim state (**floating-joystick slingshot**: `beginAimDrag`/`updateAimDrag`/`endAimDrag` take world coords and derive angle+power from the pull *relative to wherever the finger landed* — `AIM_DEAD_ZONE=26`, `AIM_FULL_PULL=300` world units — so aiming is never pinned to the station's screen corner; plus deci nudges whose step grows while held; duel turn flip resets aim toward enemy, campaign/daily keeps last); `selectedGambit` — the declaration for *this* shot, offered from `spec.gambitOptionsFor(currentShooter)` and reset every turn so it can never become a standing setting; `advanceBy(ticks)` steps the sim, with the caller deriving ticks from **wall-clock** time (`PLAYBACK_TICKS_PER_SEC=120`, catch-up clamped) — never from frame count, which ran 2x fast on 120Hz panels; trail is a plain `ArrayDeque` + `trailVersion` counter (not snapshot state) for draw-phase-only invalidation; imported-code path: verify → rebuild minus last turn → cinematic replay of opponent shot (queue); duel code build (whole match re-encoded per turn); `feedbackCode()` for bug reports; Summary construction; rewardsApplied/dustEarned handshake with UI.
- `ui/game/WorldRenderer.kt` — `WorldTransform` (letterbox fit, world↔screen) + **`RenderCache`**, which precomputes everything derivable from (system, canvas size): star positions, nebula/vignette/body gradient brushes, ring geometry, stroke widths, trail colour LUT. The DrawScope functions then only issue draw calls, allocating nothing per frame: space backdrop (nebulae + 150 stars, hero-star sparkles), bodies (star corona/planet rings+atmosphere+terminator/repulsor shear arcs), stations (HP arc vs rotating target reticle, antenna beacons), preview dots, trail (LUT-coloured; opponent replay = classic), comet-glow projectiles, aim arrow + power ring, floating aim stick (dead-zone ring, power arc, pull line, heading spike), anchors, explosion (seeded particles, kill flash, secondary shockwave), vignette.
- `ui/game/GameScreen.kt` — create (background: generate or decodeAndVerify; invalid ⇒ "the physics noticed" error screen); frame loops (ambient clock; FLYING wall-clock stepper; RESOLVING explosion anim + haptic + SFX); rewards-once effect; lastDuelCode persist effect; Canvas with live `contentDescription` + gesture input (hand-rolled `awaitEachGesture`, not `detectDragGestures`, so the stick centres on the true touch-down instead of the post-slop position; anchor placement is a separate tap detector gated on `placingAnchors`). **Layout is size-class dependent** (`BoxWithConstraints`): portrait uses `TopHud`/`BottomControls` overlays; wide screens (aspect > 1.15) put `HudContent` in the left letterbox bar and `ControlsContent` in the right so the board is never covered — both layouts share those two bodies. Overlays: Handoff (hot-seat pass / code share), Summary (stars, dust ±pass note, optional ad double, next/retry/share/rematch, report-a-problem), quit dialog.
- `ui/AmbientBackdrop.kt` — drifting starfield + nebula + slow comet behind every non-match screen, clocked at ~30fps (idle screens); `OrbitRule` divider. Both excluded from the accessibility tree.
- `ui/ShareMessages.kt` — the text that leaves the app into someone else's chat; must stand alone for a stranger (`STORE_URL` hook turns codes into install links at launch). `ui/Share.kt` — share-sheet helper.
- `ui/screens/Feedback.kt` — `GGFB1` blob composition + dialog; match reports attach a verifiable replay code (pipeline: `feedback/README.md`).
- `audio/SoundManager.kt` — SoundPool wrapper over 7 synthesized SFX (`tools/gen_sfx.py`); `enabled` mirrors the profile setting, play() is a no-op when off.
- `audio/AmbienceTrack.kt` — plays `:core`'s generated pad on an `AudioTrack` in `MODE_STATIC` with hardware loop points, so an hour of drone costs no CPU after the one write. Builds off the main thread keyed on (seed, objective) so a rematch does not rebuild; `resyncPulsarPhase()` seeks to sample 0 on fire so a pulsar's tremolo tracks the pull the shot is flying through (no-op without a pulsar). Owned by MainActivity for onPause/onResume/onDestroy; every AudioTrack call is guarded — losing the drone is acceptable, crashing is not. Gated on `Profile.musicEnabled`, which is deliberately **separate** from `soundEnabled`.
- `ads/RewardedAds.kt` — see below; ships as `NoOpRewardedAds`.

## Data flow (one shot)
touch down anywhere on the board → floating stick → pull → quantize (angleDeci,power ints) → preview via same sim (~0.065ms) → FIRE → `engine.beginShot` → `advanceBy(n)` where n comes from wall-clock elapsed time (UI thread; ~µs per tick) → done → `engine.commit(result)` (rules+hash) → RESOLVING anim → next phase. Code duel: turns → `ShareCodec.encode(MatchRecord)` → messenger → peer `decodeAndVerify` → rebuilt engine + replay queue.

## Threading
Main: sim stepping (trivial cost), UI. Dispatchers.Default: system generation + code verification (100ms–3s), ambience rendering (~40ms desktop / ~150ms phone, once per system). Dispatchers.IO: DataStore writes. Audio: SoundPool and AudioTrack both mix on their own system threads; after the one static write the pad needs no application thread at all. No other concurrency.

## Persistence
Single JSON Profile in DataStore prefs. Forward-compatible (unknown keys ignored, defaults on new fields). Corrupt ⇒ default Profile (never crash). No match-in-progress persistence (D-9).
